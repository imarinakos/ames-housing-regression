# ames-housing-regression

AI-based regression model using Python to predict house prices using the Ames dataset. This project explores supervised learning techniques with a focus on model regularization and performance evaluation.

---

##  Project Structure

- `AI_Housing_Regression_Project.ipynb`: Main notebook with basic linear regression, data preparation, and evaluation.
- `Ridge_Regression_Visualization.ipynb`: Regularized regression with Ridge (cross-validated) + performance plots.
- `Lasso_Regression_Visualization.ipynb`: Regularized regression with LASSO + feature selection insights.

---

## Tools & Libraries

- Python (pandas, scikit-learn, matplotlib)
- Linear, Ridge, and Lasso regression
- Train/test split, R², and MAE evaluation metrics
- Visualization of predicted vs actual outcomes

---

## 📊 Dataset

- **Ames Housing Dataset**  
  Source: [OpenIntro Ames Data](https://www.openintro.org/book/statdata/?data=ames)

---

## How to Run

You can open any notebook in [Google Colab](https://colab.research.google.com) by uploading the `.ipynb` file. All cells are self-contained and reproducible.
